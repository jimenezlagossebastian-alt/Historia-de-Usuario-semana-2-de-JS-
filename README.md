# Gestión de Datos en JavaScript

## Descripción
Este programa permite practicar el uso de objetos, Sets y Maps en JavaScript.

También incluye recorridos con bucles y validaciones básicas de datos.

---

## Funcionalidades

- Crear productos con id, nombre y precio
- Usar Set para evitar números repetidos
- Usar Map para relacionar categorías y productos
- Recorrer datos con for...in, for...of y forEach()
- Validar información de productos

---

## Tecnologías usadas

- JavaScript
